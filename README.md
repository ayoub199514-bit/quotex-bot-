# بوت تداول Quotex — متعدد الأصول + إشعارات تليجرام

بوت تداول آلي لمنصة **Quotex** (خيارات ثنائية) مبني بـ Python، مع واجهة ويب
عبر Streamlit، استراتيجية "تلاقي ثلاثي" (RSI + MACD + Bollinger Bands)،
إدارة مخاطر أساسية، **مراقبة عدة أزواج تداول في نفس الوقت**، و**إشعارات
تليجرام فورية** عند كل صفقة.

## ⚠️ تنبيهات مهمة قبل الاستخدام

1. **لا يوجد API رسمي لـ Quotex.** هذا البوت يعتمد على مكتبة مفتوحة المصدر
   غير رسمية اسمها [pyquotex](https://github.com/cleitonleonel/pyquotex)
   تحاكي تسجيل الدخول عبر الويب سوكيت الداخلي للمنصة. استخدام أدوات كهذه:
   - قد يخالف **شروط استخدام Quotex**، وقد يؤدي لتجميد أو حظر الحساب.
   - عرضة للتوقف عن العمل إذا غيّرت المنصة نظامها الداخلي.
2. **مخاطرة مالية حقيقية.** الخيارات الثنائية أداة عالية المخاطرة، ويمكن
   خسارة كامل رأس المال المستثمر في الصفقة بسرعة.
3. **هذا ليس نصيحة استثمارية.** اختبر الاستراتيجية جيداً على حساب Demo
   وافهم كودها قبل أي استخدام حقيقي.
4. ابدأ دائماً بـ **Demo**، وراقب سلوك البوت لفترة كافية قبل التفكير في
   التحويل لحساب حقيقي.

## الميزات الجديدة في هذا الإصدار

### 1) مراقبة عدة أزواج في نفس الوقت
من الشريط الجانبي، اختر أي عدد من الأزواج (EURUSD_otc, GBPUSD_otc, ...)
عبر قائمة الاختيار المتعدد، أو أضف زوج مخصص غير موجود بالقائمة الجاهزة.
البوت يمر دورياً على كل الأزواج المختارة، ويحلل كل واحد بشكل مستقل، وينفذ
صفقة عند ظهور إشارة قوية على أي منها.

### 2) إشعارات تليجرام
فعّل الخانة من الشريط الجانبي وأدخل:
- **Bot Token**: احصل عليه من محادثة [@BotFather](https://t.me/BotFather)
  على تليجرام عبر أمر `/newbot`.
- **Chat ID**: احصل عليه من محادثة [@userinfobot](https://t.me/userinfobot).

بعد التفعيل، ستصلك رسالة فورية عند:
- بدء تشغيل البوت وإيقافه
- كل صفقة (نجاح/فشل، الأصل، الاتجاه، المبلغ)
- الوصول لحد الخسارة أو هدف الربح اليومي

## هيكل المشروع

```
quotex_bot/
├── strategy.py       # منطق الإشارات (RSI + MACD + Bollinger)
├── risk_manager.py   # حجم الصفقة + حدود الخسارة/الربح اليومية
├── notifications.py  # إشعارات تليجرام
├── bot.py            # الاتصال بالمنصة + دعم عدة أصول + حلقة التشغيل

```

## التثبيت والتشغيل (محلياً)

```bash
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## التشغيل على خادم سحابي (موصى به)

الطريقة الأفضل لتشغيل مستمر هي نشر المشروع على Streamlit Cloud أو Render:
1. ارفع الملفات على مستودع GitHub خاص (Private)
2. اربط المستودع بمنصة النشر (streamlit.io/cloud أو render.com)
3. Build command: `pip install -r requirements.txt`
4. Start command (لـ Render فقط): `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`

⚠️ الخطط المجانية عادة تُنيم الخدمة بعد فترة عدم استخدام؛ لتشغيل 24/7 حقيقي
قد تحتاج خطة مدفوعة أو VPS.

## تعديل الاستراتيجية

كل منطق الإشارات في `strategy.py` داخل `TripleConfluenceStrategy`. يمكنك
تغيير قيم RSI، فترات MACD أو Bollinger، أو استبدال الدالة بالكامل
باستراتيجيتك الخاصة طالما ترجع `"CALL"` أو `"PUT"` أو `"HOLD"`.

## إدارة المخاطر

في `risk_manager.py`:
- `stake_pct`: نسبة الرصيد لكل صفقة (الافتراضي 2%).
- `daily_loss_limit_pct`: يوقف البوت تلقائياً عند خسارة هذه النسبة يومياً.
- `daily_profit_target_pct`: يوقف البوت عند تحقيق هذا الهدف.
- `max_trades_per_day`: حد أقصى لعدد الصفقات (عبر كل الأزواج مجتمعة).

## إخلاء مسؤولية

هذا الكود مُقدَّم "كما هو" لأغراض تعليمية/برمجية، دون أي ضمان للربح أو
الأداء. المستخدم مسؤول بالكامل عن أي قرارات تداول أو خسائر مالية، وعن
التأكد من توافق استخدامه مع شروط خدمة Quotex والقوانين المعمول بها في بلده.
