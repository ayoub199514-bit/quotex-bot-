# بوت تداول Quotex

بوت تداول آلي لمنصة **Quotex** (خيارات ثنائية) مبني بـ Python، مع واجهة ويب
بسيطة عبر Streamlit، واستراتيجية "تلاقي ثلاثي" (RSI + MACD + Bollinger Bands)،
وإدارة مخاطر أساسية (حجم صفقة، حد خسارة/ربح يومي).

## ⚠️ تنبيهات مهمة قبل الاستخدام

1. **لا يوجد API رسمي لـ Quotex.** هذا البوت يعتمد على مكتبة مفتوحة المصدر
   غير رسمية اسمها [pyquotex](https://github.com/cleitonleonel/pyquotex)
   تحاكي تسجيل الدخول عبر الويب سوكيت الداخلي للمنصة. استخدام أدوات كهذه:
   - قد يخالف **شروط استخدام Quotex**، وقد يؤدي لتجميد أو حظر الحساب.
   - عرضة للتوقف عن العمل إذا غيّرت المنصة نظامها الداخلي.
2. **مخاطرة مالية حقيقية.** الخيارات الثنائية أداة عالية المخاطرة، ويمكن
   خسارة كامل رأس المال المستثمر في الصفقة بسرعة. لا تستخدم أموالاً لا
   تتحمل خسارتها.
3. **هذا ليس نصيحة استثمارية.** الاستراتيجية المرفقة مبنية على مؤشرات فنية
   شائعة كنقطة انطلاق تعليمية فقط، وليست مضمونة الربح. اختبرها جيداً على
   حساب Demo وافهم كودها قبل أي استخدام حقيقي.
4. ابدأ دائماً بـ **Demo**، وراقب سلوك البوت لفترة كافية قبل التفكير في
   التحويل لحساب حقيقي.

## هيكل المشروع

```
quotex_bot/
├── strategy.py      # منطق الإشارات (RSI + MACD + Bollinger)
├── risk_manager.py  # حجم الصفقة + حدود الخسارة/الربح اليومية
├── bot.py           # الاتصال بالمنصة (pyquotex) + حلقة التشغيل
├── app.py           # واجهة الويب (Streamlit)
└── requirements.txt
```

## التثبيت

```bash
python -m venv venv
source venv/bin/activate        # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

> إذا فشل تثبيت pyquotex عبر pip، ثبّته يدوياً:
> ```bash
> git clone https://github.com/cleitonleonel/pyquotex.git
> cd pyquotex && pip install .
> ```

## التشغيل

```bash
streamlit run app.py
```

ثم من المتصفح:
1. أدخل بريدك الإلكتروني وكلمة مرور حساب Quotex.
2. اختر "تجريبي (Demo)" — **مستحسن دائماً في البداية**.
3. حدد الأصل (مثال: `EURUSD_otc`)، مدة الصفقة، ونسبة رأس المال لكل صفقة.
4. اضغط "▶️ تشغيل" وراقب السجل المباشر.

## تعديل الاستراتيجية

كل منطق الإشارات في `strategy.py` داخل `TripleConfluenceStrategy`. يمكنك:
- تغيير قيم RSI (30/70 الافتراضية).
- تغيير فترات MACD أو Bollinger.
- استبدال دالة `generate_signal` بالكامل باستراتيجيتك الخاصة (Moving
  Average Crossover، Price Action، إلخ) طالما ترجع `"CALL"` أو `"PUT"`
  أو `"HOLD"`.

## إدارة المخاطر

في `risk_manager.py` يمكنك التحكم بـ:
- `stake_pct`: نسبة الرصيد لكل صفقة (الافتراضي 2%).
- `daily_loss_limit_pct`: يوقف البوت تلقائياً عند خسارة هذه النسبة يومياً.
- `daily_profit_target_pct`: يوقف البوت عند تحقيق هذا الهدف (اختياري).
- `max_trades_per_day`: حد أقصى لعدد الصفقات لمنع الإفراط بالتداول.

## إخلاء مسؤولية

هذا الكود مُقدَّم "كما هو" لأغراض تعليمية/برمجية، دون أي ضمان للربح أو
الأداء. المستخدم مسؤول بالكامل عن أي قرارات تداول أو خسائر مالية، وعن
التأكد من توافق استخدامه مع شروط خدمة Quotex والقوانين المعمول بها في
بلده.
